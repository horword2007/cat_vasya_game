# Игра от кота Василия

Ролевая игра с пошаговой боевкой. Учебный проект по ООП на Python.

## Структура проекта

- `unit.py` - абстрактный класс Unit
- `character.py` - класс Character (воин, маг, охотник)
- `monster.py` - класс Monster
- `spell.py` - классы заклинаний
- `main.py` - тестирование

## Требования

- Python 3.8 или выше
